# self-growth — propose-only methodology log

The agent grows its own methodology WITHOUT any team runtime, via an append-only log:

- `insight-log-core.md` [S] — identity-agnostic, shareable methodology entries.
- `insight-log-private.md` [P] — any entry naming a person or carrying an identity-bearing opinion.

## Promotion rule (agent may only PROPOSE)

The agent writes entries at `status: proposed`. `status: ratified` requires the **operator's
hand-authored commit marker**. The agent **MUST NEVER** self-promote to ratified. An
assertion-only entry (no demonstration, no operator marker) is rejected.

This mirrors the donor `aocc-ai-advisory` self-growth discipline.
